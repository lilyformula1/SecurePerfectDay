# 🛡️ SecurePerfectDay - Advanced Malware Analysis for Your Perfect Day

## 📖 Project Overview
A perfect day is a day when you are safe from hackers. **SecurePerfectDay** is a web-based static malware analysis tool that ensures your system remains secure, so you can enjoy your day worry-free. 

It analyzes Windows PE (Portable Executable) files (`.exe`, `.dll`) for malicious indicators. It provides detailed reports on hash values, PE headers, suspicious API calls, string indicators, entropy analysis, and a comprehensive risk assessment.

## 🛠️ Tech Stack
- **Programming Language:** Python 3.13
- **Web Framework:** Streamlit
- **Analysis Engine:** pefile, hashlib, re, math
