# 💥 CyberBoom - Advanced Static Malware Analysis Platform

## 📖 Project Overview
CyberBoom is a web-based static malware analysis tool that analyzes Windows PE (Portable Executable) files (`.exe`, `.dll`) for malicious indicators. It provides detailed reports on hash values, PE headers, suspicious API calls, string indicators, entropy analysis, and a comprehensive risk assessment.

## 🛠️ Tech Stack
- **Programming Language:** Python 3.13
- **Web Framework:** Streamlit
- **Analysis Engine:** pefile, hashlib, re, math
